# 📊 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes E-Commerce Sales data using data analytics techniques to identify business trends, customer purchasing behavior, and sales performance. The project demonstrates the complete Data Analytics workflow including data cleaning, data analysis, visualization, and dashboard creation.

The dashboard provides valuable insights into sales performance across different years, product categories, payment methods, and store types.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Compare yearly sales trends.
- Identify top-performing product categories.
- Analyze payment method usage.
- Compare sales across different store types.
- Monitor important business KPIs.
- Generate actionable business insights.

---

## 📂 Dataset Information

The dataset contains transactional sales data with the following columns:

- Sales ID
- Order Date
- Year
- Customer ID
- Product ID
- Store ID
- Quantity
- Unit Price
- Gross Amount
- Discount
- Payment Type
- Total Amount
- Sales Range
- Quantity Category

## 📌 Data Analysis Process

### 1. Data Collection
Imported E-Commerce Sales Dataset.

### 2. Data Cleaning
- Removed duplicate records
- Handled missing values
- Corrected data types
- Verified numerical columns
- Standardized column names

### 3. Data Transformation
- Created calculated columns
- Derived Year column
- Categorized sales values
- Prepared data model

### 4. Data Visualization
Created an interactive dashboard with business KPIs and charts.
